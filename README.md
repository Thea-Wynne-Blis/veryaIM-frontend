# VERYAL Frontend

VERYAL 的客户端：面向个人用户的即时通讯，**Web 与移动端同一套代码、两套布局**。同一个仓库里还带一个独立的运营后台入口。

**Vue 3 · TypeScript · Vite · Pinia · Vue Router · Lucide Icons**

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # vue-tsc 类型检查 + 生产构建
npm run preview
npm test         # Vitest
npm run e2e      # Playwright 端到端脚本
```

开发时 `/api` 与 `/ws` 默认代理到本机后端（`127.0.0.1:8080` / `127.0.0.1:9098`），要连别的环境就设 `VITE_API_PROXY`、`VITE_WS_PROXY`。

## 两个入口

| 入口 | 路由 | 用途 |
|---|---|---|
| `index.html` | `/app/chat` | IM 客户端：消息、通讯录、收藏、我的 |
| `system.html` | `/system/` 或 `/system.html` | 运营后台：概览、用户、群、举报、敏感词、管理员、审计 |

两个入口共享组件与设计令牌，但登录态、路由和 Token 完全分开。IM 客户端接真实后端（`/api/v1` + Bearer），不是本地演示数据。

## 界面

### 桌面端

```text
┌──────┬──────────────┬──────────────────────────┬────────────┐
│ rail │  会话列表     │  聊天主区                 │  详情       │
│ 68px │  348px       │  flex                    │  306px     │
└──────┴──────────────┴──────────────────────────┴────────────┘
```

- **rail**：消息 / 通讯录 / 收藏，底部是设置与账号入口；激活项带左侧指示条，未读红点带描边
- **会话列表**：置顶分组、未读筛选、**内联搜索**——输入即过滤会话，同时匹配好友备注/昵称，未聊过的人点一下直接建私聊；`⌘K / Ctrl+K` 聚焦搜索框
- **聊天主区**：吸顶头部、按作者分组、悬停才显示时间与已读状态；右键消息可复制、引用、翻译、转发、多选、删除
- **详情**：群公告、成员、会话文件，可折叠；桌面端不再有独立的全局搜索弹窗

窗口收窄时依次隐藏详情栏、压缩列表，≤ 768px 切换为移动端布局。

### 移动端

```text
┌─────────────────────┐     ┌─────────────────────┐
│  消息      ＋        │     │ ← 林知夏       ⋯    │
│  [ 搜索 ]           │     │─────────────────────│
│─────────────────────│     │  · 消息流            │
│ ◯ 会话  时间  未读   │ ──▶ │                     │
│ ◯ 会话  时间  未读   │     │─────────────────────│

```

- 底部标签栏毛玻璃 + 安全区适配；收藏从「我的」进入
- 聊天页覆盖式进入，带滑入与淡入；气泡最大宽度 76%
- 移动端搜索仍是全屏页，桌面端已改为侧栏内联搜索

### 搜索与收藏

- **会话内搜索**：按关键词搜当前会话的文本与表情，命中高亮，点结果直接跳到那条消息并定位
- **收藏**：消息收藏后跨会话聚合，图片/视频/语音/文件按媒体网格与列表展示，可直接预览
- **文件预览**：图片（缩放）、PDF、音视频、文本/代码（自动识别 UTF-8/UTF-16/GB18030）、docx / xlsx / pptx（前端解压解析）、zip 目录；不支持的格式给出下载入口

## 消息与实时

- 建连前先 `POST /auth/ws-ticket` 换一张 60 秒一次性 ticket，token 不出现在 WS URL
- 推送带完整消息体时直接插入列表，不再回查接口；大群只带 `seq` 游标，按 120ms 窗口合并后增量拉取
- 发送采用**乐观渲染**：本地先占位，服务端确认到达时**原地升级**。列表 key 用 `clientMsgId`，节点不重建，所以气泡不会闪一下或重播动画
- 按 `messageId` / `clientMsgId` 去重；已读上报节流 1s；断线按 1s→15s 指数退避重连，每次重新换票
- 低频轮询兜底：长连接健康时 60 秒一次同步，未连接时回到 3 秒

实现集中在 `src/api/realtime.ts` 与 `src/stores/chat/`。

## 文件与媒体

- 上传用 `XMLHttpRequest` 报字节进度，输入区上方一条 2px 进度条；超过 8MB 自动切片，支持断点续传与取消
- 进度分三段：`prepare`（读图片尺寸、抓视频封面）→ `upload`（百分比）→ `send`（等服务端确认）
- 图片先取服务端缩略图，点开才拉原图；GIF 必须走原图，否则动图变静态首帧；SVG、HEIC 等不能安全内联的格式降级为文件卡片
- 视频的宽高、时长、封面全部在浏览器生成，封面作为普通图片上传后用 `coverFileId` 引用，服务端不依赖 ffmpeg
- 已加载的媒体按 `fileId` 缓存 object URL（LRU 48 条），切走再回来不重新下载；滚动位置按会话记忆，只有首次打开才贴底
- 图片/视频消息记录宽高，用 `aspect-ratio` 先占位，避免加载完把气泡顶开

## 视觉

结构学 [BoardUI](https://www.boardui.com/zh-hans) 的克制层级与细边框，手感学 [bencho.dev](https://bencho.dev/) 的微交互；IM 需要长时间使用，动效整体收敛。

- **墨色 + 玉色**：正文 `#16181A`，主色 `#12876F`，不用企业蓝也不照搬微信绿
- **暖中性底**：画布 `#F5F5F2`，比纯灰更耐看
- **渐进圆角与低对比阴影**：按层级递增，阴影只用 5%~8% 透明度
- **气泡不对称圆角**：靠近发送者一侧收窄，形成指向感
- **输入区不画框**：文字直接浮在画布上，只用一条细线与消息流分隔
- 全部设计令牌集中在 `src/styles/tokens.css`，深色模式是完整令牌覆盖；`?theme=dark` 或左下角按钮切换

动效只保留必要的部分：会话项错峰入场、未读角标 pop-in、按钮按压回弹、头像微旋转、在线点呼吸。**消息气泡刻意不做入场动画**——曾经延迟 260ms 让「发消息看起来卡一下」，现在发送即显示；只有切换会话时的首批消息会播放一次逐条流动。全部尊重 `prefers-reduced-motion`。

## 工程化

- `npm run build` 先跑 `vue-tsc` 再做生产构建，类型错误不会带进产物
- `npm test` 覆盖纯函数与轻量 composable：消息排序/去重、搜索、收藏、文件预览识别、展示格式化
- `npm run e2e` 与 `tools/verify-*.mjs` 是基于 Playwright 的功能校验，需要后端与 Chromium 可用
- 无障碍：导航与图标按钮均有 `aria-label`，当前页用 `aria-current`，筛选 chips 用 `tablist`，焦点环统一 `2px solid var(--accent)`

## 已知取舍

- 消息超过撤回窗口后「删除」只在本机隐藏（`localStorage`），因为后端没有全员删除接口
- `/content` 需要 Bearer 头，`<video src>` 带不上，所以播放前会整份 `fetch` 成 object URL；慢网络下大视频要等下载完。要改成边下边播，需要后端给本地存储补短时效签名直链
- 历史消息里的引用关系与消息翻译依赖后端已上线的字段/代理；转发附件受「文件必须属于发送者」约束，别人的文件不能转到其它会话
- 浏览器 Web Push 订阅还没有接 UI（后端接口已就绪）

前端架构与接口约定见后端仓库的 `docs/FRONTEND-ARCHITECTURE.md`。
